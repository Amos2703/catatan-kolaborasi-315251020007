Hal yang terasa sedikit menantang di awal adalah membiasakan diri melakukan commit secara bertahap dan menuliskan pesan commit yang deskriptif sesuai aturan. Ke depannya, saya ingin mempelajari lebih lanjut mengenai fitur branching dan merging di Git agar bisa berkolaborasi dalam tim dengan lebih efektif tanpa menimpa pekerjaan anggota lain. saya juga ingin membiasakan diri menggunakan Git agar kedepannya saya tidak harus menggunakan bantuan dari AI dan bisa menggunakan Git lebih cepat dan leluasa, sehingga tidak memakan waktu saat menjalankan tugas.
